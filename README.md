# Anil Kumar — Personal IT Portfolio

A responsive, static portfolio website with a modern dark theme. No framework or build step is required.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and current year

## Personalize before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR_EMAIL@example.com` with your email address.
3. Replace the generic LinkedIn and GitHub links with your actual profile URLs.
4. The featured BSS/CRM digital transformation case study was added from the project details you supplied. Review the description and metrics for accuracy before publishing. The remaining three cards are clearly labeled as portfolio concepts; replace them with verified projects or remove them.
5. Review the skill list and remove anything you do not want to claim as a skill.
6. Optionally add a profile photo, resume PDF, certifications, location, and work history.

## Preview locally
Double-click `index.html` to open it in a browser. For the best development experience, use VS Code with the Live Server extension.

## Publish free with GitHub Pages
1. Sign in to GitHub or create an account at https://github.com/.
2. Create a new public repository named `anil-kumar-portfolio` (or another name you prefer).
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site. The Pages settings will show the published URL, typically `https://YOUR-USERNAME.github.io/anil-kumar-portfolio/`.

## Notes
- Hosting is free for a public GitHub repository using GitHub Pages, subject to GitHub's current terms.
- Google Fonts requires an internet connection; the site otherwise uses system font fallbacks.
- This is a static portfolio. A contact form would require a form service or backend; the current email button opens the visitor's email app.
