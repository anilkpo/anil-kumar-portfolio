Project overview

Spearheaded the end-to-end digital transformation of legacy monolithic Business Support Systems (BSS) into a modern, cloud-native, microservices-driven architecture. The initiative focused on modernizing digital customer lifecycle management, automating provisioning workflows, scaling billing engines, and implementing robust CI/CD automation to accelerate time-to-market for new digital services.

System architecture

01Frontend & presentation

Responsive web portals and API-driven interfaces using an API Gateway for routing, rate limiting, and JWT-based authentication.

02Microservices application tier

Customer Management, Product Catalog, Order Management, Billing, and Rating Engine services, containerized with Docker and orchestrated on Kubernetes (EKS).

03Integration & event bus

Asynchronous, event-driven communication using Kafka/RabbitMQ patterns for domain decoupling and real-time state synchronization.

04Data & persistence

Distributed relational and NoSQL data stores designed to support horizontal scalability, high availability, and ACID requirements for critical billing and charging records.

05DevOps & infrastructure

Infrastructure as Code using Terraform/Ansible and automated CI/CD pipelines managed through GitLab CI.

Challenges addressed

Legacy monolith bottlenecks

Addressed tight coupling associated with peak-hour latency, slow releases, and cascading failures.

Scaling and resource utilization

Moved workloads to containers and enabled automated cluster scaling in response to traffic.

Deployment friction

Replaced manual, error-prone release steps with automated pipelines and rolling deployments.

Data silos and integration delays

Established an API-first approach to connect fragmented legacy systems and support customer lifecycle management.

My contributions

  • Architecture blueprint: Led high-level and low-level design for migrating monolithic BSS modules to scalable microservices.
  • Cloud and orchestration: Configured and managed enterprise Kubernetes clusters, including container deployment, resource limits, and self-healing configurations.
  • CI/CD engineering: Built and maintained GitLab pipelines with code-quality checks, security scanning, container builds, and zero-downtime rolling deployments.
  • Infrastructure and cost optimization: Provisioned and managed secure AWS infrastructure, auto-scaling policies, IAM controls, and resource monitoring.
  • Technical leadership and knowledge transfer: Led technical reviews, mentored engineering teams on cloud-native practices, and facilitated operational-readiness workshops.
